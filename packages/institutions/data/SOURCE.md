# Source

`universities.json` is a compact version (name, country, email domains) of
`world_universities_and_domains.json` from
https://github.com/Hipo/university-domains-list, commit `a8fb652f5032801de7125a814aedf213b262a1a4`
(downloaded 2026-11-03). 10272 universities.
